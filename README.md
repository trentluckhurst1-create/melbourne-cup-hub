# Melbourne Cup Hub 2026

A dedicated Melbourne Cup intelligence centre covering nominations, horse profiles, weights, order of entry, markets, Timeform ratings supplied by the user, form, lead-ups, international raiders, news, connections, historical analysis and race-day intelligence.

## Current build

The repository now contains the first working front-end shell:

- Cup Dashboard
- Nominations
- Horse Profiles
- Weights & Handicap
- Order of Entry
- Markets
- Timeform
- Form Guide
- Lead-up Tracker
- International Raiders
- Ratings & Rankings
- News Centre
- Jockeys & Trainers
- Historical Cup
- Race Analysis
- Final Field / Race Day

## Data principles

Changing data is timestamped and source-attributed. Historical states are preserved rather than silently overwritten. Subscription-only Timeform information is only stored from user-authorised data supplied to the project.
